## 维护建议

- 产品定位、设计公理和全局约束统一维护在 00 文档；其他文档引用，不复制定义。
- 玩家与世界状态规则归 01/03；攻防执行规则归 02；技术实现和安全边界归 04；玩家可见交互与游戏端集成归 05。
- 新增内容先判断其主要归属文档；若涉及跨文档行为，在主归属文档定义规则，在其他文档只添加接口或章节引用。
- 本次整合保留原文已有的交叉引用编号；新增内容使用“新增”小节，不强行重编号原章节。
- `00` 定义玩法核心、产品目标、Mod 内容包边界与《The Rusty Dream》叙事框架。
- `01` 定义玩家/队友属性、队友硬件、人性值与持久化状态。
- `02` 定义目标 HVM、ICE、Key、Preload、代理链、快速破解与协同处决规则。
- `03` 定义大型城市基础设施目标及其宏观效果。
- `04` 定义 ToolRT、Scorpion、Shark、Krab、HardwareVM、AgentPool、TaskPool 与 NRengine 生命周期管理。
- `05` 定义扫描快捷键、CyberspaceGUI、Cyberspace3D 表现和 CP77 Mod 模块嵌入。
- 尚未明确的术语/数值（例如 Rare、Num、“按速率/周度”中的“周度”）保留为待确认项，不擅自补全。
